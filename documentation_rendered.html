1. Project Overview & Purpose

1.1 The Challenge

Electronic waste is expanding at three times the rate of average municipal solid waste. Obsolete smartphones, damaged circuit boards, laptop adapters, and cracked tablets frequently end up in domestic landfills or remain forgotten in households because recycling facilities are inconvenient, lack immediate feedback, and offer no tangible rewards.

1.2 The Solution

Encycle Bank is an autonomous, touchscreen-based smart e-waste collection kiosk powered entirely by a Raspberry Pi. It provides an interactive deposit experience:
- Instant Authentication: Quick access using a mobile phone number or email with one-time verification.
- Visual Inspection: High-resolution camera preview and photo verification of deposited electronics.
- Automated Trapdoor: Motorized collection door controlled directly by the Raspberry Pi that unlocks upon verification, stays open for 15 seconds, and automatically secures the intake bin.
- EcoCredit Rewards: Users earn reward points based on device condition and earn milestone bonuses for long-term recycling.
- Paperless Receipts: Instant WhatsApp notifications and HTML email certificates sent directly to the user's phone.

2. Raspberry Pi System Architecture

The entire kiosk operates autonomously on a single Raspberry Pi 4 Model B or Raspberry Pi 5. No auxiliary microcontrollers or external PCs are required.

How the Subsystems Interact:

  1. Frontend Interface: A responsive HTML5/CSS3 touchscreen application runs in fullscreen mode inside Chromium.
  2. Backend Engine: A local Flask web server processes user sessions, coordinates camera frame streams, and logs deposits.
  3. Hardware Control: The backend directly drives the servo motor using the Raspberry Pi's hardware pulse-width modulation (PWM) subsystem via pigpio to ensure smooth door movement without jitter.
  4. Data Persistence: An embedded SQLite database maintains customer balances, device logs, and system counters with high-performance Write-Ahead Logging (WAL).
  5. Notification Services: Asynchronous background workers dispatch WhatsApp messages and emails without delaying the kiosk touch interface.

3.2 Electrical Wiring Diagram (Direct Raspberry Pi Connection)

[!IMPORTANT]
Electrical Isolation Rule: Never power a high-torque metal-gear servo (MG996R) directly from the Raspberry Pi's 5V pins. Moving servos draw up to 2.5 Amps when turning, which drops the Raspberry Pi's input voltage and causes brownouts. Always use a dedicated external 5V supply and connect its ground wire to the Raspberry Pi ground pin (Common Ground).

Raspberry Pi Pinout Reference:

  • Physical Pin 12 (BCM GPIO 18): PWM Signal connected to Servo Orange wire.
  • Physical Pin 6 (Ground): Common Ground connected to Servo Brown wire and Power Supply (-) terminal.
  • External Power Supply (+5V): Connected directly to Servo Red wire.

5. The Kiosk User Journey (Screens 1 to 7)

The kiosk interface consists of seven sequential screens optimized for touchscreens:

[Screen 1] Attract Screen ──► [Screen 2] Sign-In ──► [Screen 3] OTP Verification
                                                            │
[Screen 6] Review Summary ◄── [Screen 5] Camera ◄── [Screen 4] Category & Stage
         │
         ▼
[Screen 7] Success Modal + Trapdoor Opens + Digital Receipt Sent

Screen 1: Ambient Attract Mode

  • Purpose: Displays welcome graphics, environmental impact statistics, and an animated invitation to touch the screen.
  • Interaction: Touching anywhere wakes the interface and transitions to Screen 2.

Screen 2: User Identification

  • Purpose: Fast customer identification via Mobile Number or Email Address.
  • Interaction: The user enters their phone number or email using the built-in on-screen keypad. The system checks whether the user is a returning recycler or a new visitor.

Screen 3: Verification & Registration

  • Purpose: Authenticates the user and prevents fraudulent deposits.
  • Interaction: A 4-digit code is dispatched to the user's WhatsApp or Email. Once entered, returning users see their existing credit balance, while new users have an account created automatically.

Screen 4: Device Category & Damage Stage

  • Purpose: Classifies the electronic item being deposited.
  • Categories: Mobile Phones, Laptops, Tablets, Accessories, Circuit Boards / PCBs.
  • Damage Stages:
  • Stage 1 (Minor Wear): Device is functional with cosmetic scratches (Awards highest points: 25 pts).
  • Stage 2 (Functional / Screen Damage): Broken display, faulty battery, or unresponsive touch (Awards 15 pts).
  • Stage 3 (Total Crash / Scrap): Non-working electronics, shattered glass, water-damaged logic boards (Awards 5 pts).

Screen 5: Camera Inspection & Photo Capture

  • Purpose: Records proof-of-deposit images for inventory and quality auditing.
  • Interaction: The live camera feed displays targeting brackets. The user taps "Capture Photo" to snap an image, with options to retake or proceed.

Screen 6: Deposit Summary & Condition Notes

  • Purpose: Provides a transparent overview of the transaction before the item is dropped into the bin.
  • Interaction: The user reviews the device category, damage stage, points to be earned, and captured photo, with an optional on-screen keyboard to enter model remarks or notes.

Screen 7: Collection Door Opening & Completion

  • Purpose: Unlocks the physical intake door, awards points, and delivers the digital receipt.
  • Interaction:
    1. The Raspberry Pi activates the servo motor, opening the intake door to a 90° angle.
    2. A visual and audio countdown timer holds the door open for 15 seconds for deposit.
    3. The door smoothly returns to the closed position and locks.
    4. An animated progress bar updates the user's EcoCredit balance and displays their unique tracking ID (e.g., devct_32).
    5. The kiosk automatically resets to Screen 1 after 8 seconds, ready for the next recycler.

6. EcoCredit Reward System & Milestone Bonus

The kiosk uses a gamified incentive structure:

6.1 Base Reward Points

  • Stage 1 (Minor Wear): 25 EcoCredits
  • Stage 2 (Moderate Damage): 15 EcoCredits
  • Stage 3 (Total Crash): 5 EcoCredits

6.2 Eco Milestone Progress & Bonus Multiplier

Every deposit contributes toward the user's 100% Green Milestone:
- Stage 1: Contributes +35% toward the milestone (est. 95% material recovery).
- Stage 2: Contributes +25% toward the milestone (est. 70% material recovery).
- Stage 3: Contributes +15% toward the milestone (est. 45% material recovery).

When a user's cumulative progress reaches or exceeds 100%:
- An automatic +10 Bonus EcoCredit reward is granted instantly.
- The user's progress bar resets, starting progress toward the next milestone reward.

7. Digital Notifications (WhatsApp & Email Receipts)

To avoid printing paper receipts, the kiosk issues digital receipts asynchronously:

7.1 WhatsApp Receipt (UltraMsg Gateway)

A formatted WhatsApp message is dispatched immediately upon deposit containing:
- 🌿 Official Confirmation Header from Encycle Bank / Kites Robotics.
- Unique Tracking Code: e.g., devct_32.
- Item Summary: Category, Selected Condition Stage, and Recovery Ratio.
- EcoCredits Earned: Breakdown of base points, milestone bonuses, and new total balance.
- Timestamp & Location: Verified drop-off confirmation.

7.2 Email Certificate (Gmail SMTP)

A responsive HTML certificate is sent to the user's inbox featuring:
- High-contrast visual deposit certificate.

8. Raspberry Pi Setup & Deployment Guide

8.1 Prerequisites

  • Raspberry Pi 4 Model B (2GB or higher) or Raspberry Pi 5.
  • Raspberry Pi OS (64-bit Bookworm with desktop).
  • 16GB+ MicroSD Card or USB SSD.
  • Touch display and USB camera connected.
  • Servo motor wired to GPIO 18 with external 5V power.

8.2 Automated 1-Script Installation

On the Raspberry Pi terminal, run:

cd /home/pi/Raspberry
chmod +x scripts/*.sh
sudo bash scripts/setup_pi.sh

What the setup script does automatically:

  1. Installs all system dependencies (python3-picamera2, pigpio, chromium-browser, unclutter, sqlite3).
  2. Configures user permissions for GPIO and camera interfaces.
  3. Enables and starts the pigpiod hardware PWM daemon.
  4. Creates a Python virtual environment and installs application libraries.
  5. Registers the kiosk as a systemd background service so it starts automatically on power-up.
  6. Sets up Chromium in fullscreen kiosk mode (--kiosk) and hides the mouse cursor using unclutter.

8.3 System Commands Reference

# Check kiosk service status
sudo systemctl status ewaste-kiosk

# Restart kiosk backend
sudo systemctl restart ewaste-kiosk

# View real-time application logs
journalctl -u ewaste-kiosk -f

# Test the camera hardware
python3 scripts/test_pi_camera.py

# Test the servo door motor (opens for 5s and closes)
python3 scripts/test_pi_servo.py

9. Feature Implementation & Expansion Guide

This section explains how to add the five most requested features to the kiosk.

9.1 Feature 1: AI Computer Vision E-Waste Classifier (YOLO / TFLite)

The Concept:

When an item is placed in the inspection bay on Screen 5, the Raspberry Pi analyzes the camera feed to automatically identify the electronic device (smartphone, laptop, PCB) and recommend the correct damage stage, eliminating human error.

Implementation Architecture:

Camera Frame ──► Lightweight YOLOv8 Nano / TFLite Model ──► Category & Stage Prediction ──► UI Auto-Selection

Steps to Implement:

  1. Model Selection: Use an optimized YOLOv8 Nano model (yolov8n.tflite) trained on electronic waste images (phones, screens, circuit boards).
  2. Inference Engine: Run the model using TensorFlow Lite Runtime (tflite-runtime) on the Raspberry Pi CPU (takes ~80-120ms per inference).
  3. Backend Integration: Create an inference endpoint that takes the captured camera image, executes model prediction, and returns the detected category with a confidence score.
  4. UI Update: On Screen 5, the interface automatically pre-selects the recognized device category and highlights the detected damage stage.

9.2 Feature 2: Precision Weight Measurement (HX711 Digital Scale)

The Concept:

A digital load cell installed beneath the intake hopper measures the exact weight in grams of deposited electronics. This prevents empty-shell deposits and allows bonus points to be awarded for heavy electronic components (such as transformers or circuit boards).

Implementation Architecture:

Intake Hopper ──► 4x Strain Gauge Load Cells ──► HX711 Amplifier ──► RPi GPIO (Pins 5 & 6) ──► Grams Calculation

Steps to Implement:

  1. Hardware Setup: Mount a 5kg or 10kg load cell under the deposit floor. Wire the HX711 amplifier to Raspberry Pi GPIO Pin 5 (Data) and Pin 6 (Clock).
  2. Calibration: Use a known weight (e.g., a 200g phone) to determine the scale multiplier and tare the base weight on startup.
  3. Anti-Fraud Logic: If the recorded weight is less than 50 grams for a smartphone, the kiosk displays a prompt asking the user to confirm the deposit before the door unlocks.

9.3 Feature 3: RFID / NFC Smart Card Tap-to-Recycle

The Concept:

University student IDs, corporate employee badges, or municipality green cards can be tapped on an NFC reader to log in instantly, bypassing phone number entry and OTP verification.

Implementation Architecture:

RFID Card Tap ──► RC522 SPI Module ──► Raspberry Pi SPI Bus ──► Database Lookup ──► Instant User Sign-In

Steps to Implement:

  1. Hardware Setup: Connect an RC522 RFID reader to the Raspberry Pi's SPI header pins (SDA on Pin 24, SCK on Pin 23, MOSI on Pin 19, MISO on Pin 21).
  2. Database Field: Add an rfid_card_id column to the users table.
  3. Sign-In Flow: A background listener watches for card taps. When a known card ID is detected on Screen 1, the kiosk immediately authenticates the user and jumps straight to Screen 4 (Category Selection).

9.4 Feature 4: Instant Cashback via UPI / Digital Wallet

The Concept:

In addition to or instead of loyalty EcoCredits, recyclers can choose to receive direct monetary cash payouts sent straight to their UPI address (e.g., phone@upi) or bank account.

Implementation Architecture:

Screen 6 Review ──► Select "Instant Cash" ──► Enter UPI ID ──► Payout Gateway API ──► Direct Bank Transfer

Steps to Implement:

  1. Payout Rate Table: Define monetary scrap rates per condition stage (e.g., Stage 1: ₹250, Stage 2: ₹120, Stage 3: ₹40).
  2. Payment Gateway Integration: Connect the backend to a verified payout API (such as Cashfree Payouts, RazorpayX, or Stripe Connect).
  3. Verification: Once the deposit door closes securely, the payment API executes the payout transfer and sends confirmation via WhatsApp and SMS.

9.5 Feature 5: Central Cloud Dashboard & Fleet Synchronization

The Concept:

A fleet of kiosks deployed across universities, shopping malls, and corporate offices synchronizes all deposit records to a central cloud dashboard in real time, allowing centralized monitoring of bin capacity, user activity, and total collected e-waste.

Implementation Architecture:

Local Raspberry Pi ──► Background Sync Worker ──► HTTPS / REST ──► Central Cloud Database (PostgreSQL / Supabase)

Steps to Implement:

  1. Sync Flag: Add an is_synced column to the local SQLite database.
  2. Background Daemon: A lightweight background thread checks every 5 minutes for un-synced transactions.
  3. Offline Resilience: If the internet connection goes down, transactions continue saving locally without interruption. When internet connectivity is restored, the daemon automatically uploads all accumulated records.

10. Owner Administration, Maintenance & Diagnostics

10.1 Accessing Owner Diagnostics

The kiosk includes a hidden administrative menu for testing hardware and adjusting settings on-site:
1. On any screen, locate and tap the 🛠️ Kiosk Tools button at the bottom-right corner.
2. When prompted, enter the Master Owner PIN: 8611.

10.2 Available Diagnostic Tools

  • Test Fire Trapdoor: Triggers a full open-hold-close door actuation cycle to verify motor mechanics.
  • Dynamic Points Configuration: Adjust the EcoCredits awarded for Stages 1, 2, and 3 without restarting the system.
  • Camera Live Diagnostic: Check camera sensor health, active resolution, and switch between CSI camera and USB webcam.
  • Transaction Audit Log: View all deposited devices and customer profiles directly on the touchscreen.
  • System Reboot / Shutdown: Safely power down or reboot the Raspberry Pi without pulling the power cable.
